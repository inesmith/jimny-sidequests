# 01 / Overview

**Jimny Side Quests** is a year-round adventure and community mobile experience for South African Suzuki Jimny owners, developed in collaboration with **Jimny Gathering**.

The application extends the community spirit of the annual Gathering through interactive quests, an Adventure Passport, location-based exploration, and smaller Meet & Greet experiences.

### The Research Gap

> Jimny Gathering lacks consistent year-round community engagement and experiences, which limits its ability to keep Jimny owners connected and actively involved beyond the annual gathering.

Research interviews with Jimny owners highlighted a strong community identity, alongside barriers such as travel distance, scheduling, and inconsistent awareness of local events.

Side Quests responds to these insights by creating opportunities for owners to explore, participate, and connect throughout the year.

# 02 / The Concept

## Adventure Is Better Together.

Jimny Side Quests introduces a year-round adventure experience built around three elements.

### Explore

Discover themed challenges, nearby adventure destinations, off-road trails, and upcoming community experiences.

### Connect

Find nearby Jimny owners, exchange Waves, organise Meet & Greets, and participate in community experiences.

### Collect

Complete Side Quests, earn digital stamps, and build a personalised Adventure Passport that documents memorable experiences.

**The adventure doesn't end when the Gathering does.**

---

# 03 / Project Aim

Jimny Side Quests aims to:

- Encourage year-round community engagement.
- Create accessible opportunities for adventure and exploration.
- Help Jimny owners connect with one another.
- Encourage participation through interactive quests and rewards.
- Transform adventures into lasting memories through a digital passport.
- Strengthen the relationship between Jimny Gathering and its community beyond the annual event.

# 07 / Application Features

## Side Quests

Jimny owners can discover and complete themed adventures, including:

- Get It Dirty
- Convoy & Coffee
- Sleep Under the Stars
- Find Your Twin
- Road Less Travelled
- Watch the Sunset
- Watch the Sunrise
- Start a Meet & Greet
- Create a Convoy
- Park Buddies
- Spot the Wild
- The Jimny Wave

Each quest provides a description, difficulty level, requirements, and steps.

Users can track progress, submit photographic evidence, and collect Adventure Passport stamps.

## Adventure Passport

Users can create a personalised Adventure Passport, collect stamps for completed quests, and revisit their adventure memories.

## Adventure Discovery

Users can explore nearby destinations using maps, location services, Google Places, and curated destination information.

Google Places results do not independently verify trail access or vehicle suitability.

## Jimnys Near You

Participating owners can opt into nearby visibility and exchange Waves with other Jimny owners.

Nearby discovery requires location access and participating accounts.

## Meet & Greets

Users can create experiences with a title, date, location, message, and cover photo.

Invitations can be shared using the device share sheet or the nearby-owner invitation functionality.

## Upcoming Experiences

Users can browse upcoming experiences, view event details, and RSVP.

## Notifications

Notifications provide information about community interactions, invitations, and experiences.

## Profile

Users can manage their profile, view their adventures, access their Adventure Passport, and review their experiences.

# 11 / Running the Application

Jimny Side Quests was developed using React Native, Expo, TypeScript, and Firebase.

The application was developed and tested primarily on an iPhone 16 Pro Max and iOS Simulator.

## Option 1 — iOS Simulator

**Requirements:**

- macOS
- Xcode
- An installed iOS Simulator runtime

Open the project in VS Code:

```bash
code .
```

Start Expo:

```bash
npx expo start
```

Open the simulator:

```text
Xcode → Open Developer Tool → Simulator
```

Press `i` in the Expo terminal to launch the application if supported by the installed development environment.

If a native development build is required:

```bash
npx expo run:ios
```

Ensure Xcode and the simulator are configured correctly.

## Option 2 — Android Emulator

Install Android Studio and create an Android Virtual Device.

Start the emulator and run:

```bash
npx expo start
```

Press `a` in the Expo terminal if supported.

If a native development build is required:

```bash
npx expo run:android
```

## Option 3 — Physical Device

The application can be tested on a compatible iPhone or Android device.

1. Connect the phone and development computer to the same Wi-Fi network.
2. Start Expo using `npx expo start`.
3. Scan the QR code using a compatible Expo Go installation if supported by the project's SDK and native modules.
4. Otherwise, install a development build.
5. Sign in using an authorised assessment account.
6. Allow location and photo permissions when needed.

If the device cannot connect to the development server:

```bash
npx expo start --tunnel
```

**Important:** Expo Go compatibility depends on the SDK version and native dependencies. A development build may be required.

# 12 / Firebase & API Configuration

Jimny Side Quests uses Firebase for authentication, database operations, image storage, and backend functionality.

Firebase configuration is located at:

```text
src/firebase/firebase.ts
```

The application uses Google Places for location and destination discovery.

The API key is read from:

```env
EXPO_PUBLIC_GOOGLE_PLACES_API_KEY=YOUR_GOOGLE_PLACES_API_KEY
```

When a key is supplied for assessment, create a `.env` file in the project root and add the value.

Do not commit private credentials, service-account keys, or assessment passwords.

Some features require:

- Internet connectivity
- Firebase backend access
- Location permissions
- Existing community or experience data
- Multiple participating test accounts
- Google Places API access

Lecturers may contact the developer for any required assessment credentials or configuration.

# 19 / Reflection

Jimny Side Quests began with a simple question:

**How can the feeling of belonging at the Jimny Gathering continue after everyone drives home?**

The project explores how interactive development can create meaningful experiences beyond a digital screen.

Rather than encouraging users to spend more time on their phones, Jimny Side Quests encourages them to go outside, explore new places, meet new people, and create memories.

Through adventure discovery, interactive challenges, community engagement, and collectible passport stamps, the application connects digital interaction with real-world experiences.

An important milestone was presenting the concept to Jimny Gathering.

The organisation approved the idea, creating a meaningful connection between academic creative practice and a real-world community.
